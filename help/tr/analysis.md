# Analiz

Analiz modülü, yüklenen mesh için detaylı sayısal analiz sonuçlarını gösterir.

## Hesaplanan değerler

- Minimum
- Maksimum
- Ortalama
- Toplam sapma
- Standart sapma
- RMS
- Düzlem maksimum sapması
- Düzlem RMS sapması
- Machine Health Score
- Kalite durumu
- Smart Diagnostic
- Mekanik teşhis
