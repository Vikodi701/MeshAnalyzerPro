# Panel

Panel modülü, açılan mesh dosyasının genel durumunu hızlıca görmenizi sağlar.

## Gösterilen bilgiler

- Machine Health Score
- Kalite durumu
- Toplam sapma
- RMS
- Düzlem sapması
- Minimum ve maksimum değerler
- Mesh boyutu
- Son analiz sonucu

## Kullanım

1. Conf, pack, csv, txt veya json mesh dosyası açın.
2. Panel otomatik olarak güncellenir.
3. Ana kalite göstergelerini bu ekrandan takip edin.
