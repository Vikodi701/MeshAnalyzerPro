# Mesh Görünümü

Mesh Görünümü modülü, yüklenen mesh verisini tablo veya grid benzeri yapıda incelemek için kullanılır.

## Amaç

Bu ekran, ölçüm noktalarını ham veriye yakın şekilde görmenizi sağlar.

## Kullanım

1. Mesh dosyasını açın.
2. Sol menüden Mesh Görünümü seçin.
3. Ölçüm noktalarını ve değerleri kontrol edin.
