# Dashboard

The Dashboard module gives you a quick overview of the currently loaded mesh file.

## Displayed information

- Machine Health Score
- Quality status
- Total deviation
- RMS
- Plane deviation
- Minimum and maximum values
- Mesh size
- Latest analysis result

## Usage

1. Open a conf, pack, csv, txt, or json mesh file.
2. The Dashboard updates automatically.
3. Use this screen to monitor the main quality indicators.
